# Molly Controller

**The handheld for the [Molly](https://github.com/DarmawanRobotics/Molly) tour guide robot, from
a Retroid Pocket 4 or any Android device in landscape.**

</div>

---

Work in progress: this app starts from
[Pashupati Controller](https://github.com/DarmawanRobotics/PashupatiController) 2.6.1 and is being
turned into the Molly handheld. It talks Molly's UDP teleop protocol
([PROTOCOL.md](https://github.com/DarmawanRobotics/Molly/blob/main/src/molly_bridge/PROTOCOL.md))
on port 9880.
